## English

Buddhist scriptures in Markdown, organized by country (language) and tradition.
Folder levels: Country → `Hán truyền` (Chinese-transmitted) / `Pali` → scripture name → files.
More countries and translations will be added over time.

## Tiếng Việt

Kinh sách Phật giáo dạng Markdown, phân theo quốc gia (ngôn ngữ) và truyền thống.
Cấp thư mục: Quốc gia → `Hán truyền` / `Pali` → tên kinh sách → file.
Sau này sẽ có thêm nhiều bộ kinh cho nhiều quốc gia.

## 中文

佛教經典（Markdown 格式），依國家（語言）與傳承分類。
目錄層級：國家 → `Hán truyền`（漢傳）／`Pali`（巴利）→ 經名 → 檔案。
日後將陸續加入更多國家的經典。

## 日本語

仏教経典を Markdown 形式で、国（言語）と伝統ごとに整理しています。
フォルダ構成：国 → `Hán truyền`（漢訳）／`Pali`（パーリ）→ 経典名 → ファイル。
今後、他の国の経典も追加していきます。

## 한국어

불교 경전을 Markdown 형식으로 국가(언어)와 전통별로 정리했습니다.
폴더 구조: 국가 → `Hán truyền`(한역) / `Pali`(빨리) → 경전 이름 → 파일.
앞으로 다른 나라의 경전도 추가될 예정입니다.

## ไทย

คัมภีร์พระพุทธศาสนาในรูปแบบ Markdown จัดหมวดตามประเทศ (ภาษา) และสายจารีต
โครงสร้างโฟลเดอร์: ประเทศ → `Hán truyền` (สายจีน) / `Pali` (บาลี) → ชื่อคัมภีร์ → ไฟล์
จะเพิ่มคัมภีร์ของประเทศอื่น ๆ ในอนาคต
